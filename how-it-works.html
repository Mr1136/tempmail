How it works

Temporary email, without the complicated part.

Vanish connects a temporary mailbox to a simple interface so you can create an address and start receiving messages almost immediately.

01

Generate an address

When you open Vanish, the service creates a temporary email address using an available Mail.tm domain. You can use the generated address immediately or choose a custom prefix and an available domain.

02

Use the address

Copy your temporary address and use it wherever a short-lived email address is appropriate. Vanish is designed for low-stakes situations where you don't want to give out your primary inbox.

03

Wait for your message

Vanish periodically checks the temporary mailbox for new messages. When a message arrives, it appears in your inbox and can be opened in the built-in viewer.

04

Delete it when you're done

When you no longer need the address, you can delete the temporary mailbox from Vanish and start again with a fresh address.

What happens behind the scenes?

Your browser → Vanish → Mail.tm API → Temporary mailbox

Vanish provides the interface and client-side functionality, while Mail.tm provides the underlying temporary email service used by the application.

Important: temporary means temporary

Do not use a Vanish address for banking, password recovery, important accounts, medical information, legal correspondence, or anything you need to retain permanently.
